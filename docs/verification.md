- Tokens：配置标准化、双模式颜色、对比度、语义与组件覆盖、品牌锁、局部继承。
- React / Vue：16 个组件的代表性 SSR 语义、原生属性、状态与声明兼容性。

- 迁移审计：导入方式与别名、框架识别、排除目录、只读扫描、报告不覆盖原文件。
- Studio：存储异常、损坏版本恢复、元数据验证、撤销重做、50 步历史上限、差异比较；Ant/CSS/BTDESIGN 风格映射、非法值拒绝、锁定继承及真实审计报告解析。

`npm run build`、Vercel 三个 API 入口类型检查、`git diff --check` 均通过。

## v0.1 独立安装与交付包（历史记录）

`npm run verify:packages` 将 tokens、React、Vue 三个实际 tarball 安装到干净临时项目，验证 16 + 16 个导出、SSR、原生输入值、主题覆盖、CSS 导出、共享 tokens 依赖，以及 `skipLibCheck: false` 的消费端类型检查。

## v0.2 文档与组件细化验证

组件目录现为 24 个组件族、37 个公开组件。新增文档实验台的代码生成已覆盖 24 个组件族的默认用法及四种参数配置，共 120 个 React 示例通过严格 TypeScript 检查，120 个 Vue SFC 通过脚本类型检查与模板编译。文档网站类型检查和 `git diff --check` 通过。

- 自动化覆盖新增 Field 的标签、说明和错误关联、RadioGroup 名称与描述分离、数字输入边界与空值、分页范围、语义化组合部件，以及新增主题规则的归一化、合并、重置与锁定。
- 独立安装实际 v0.2.0 tarball，验证 React / Vue 各 37 个导出、Field / Table 组合 SSR、数值输入、分页、CSS 与共享主题依赖；消费端严格类型检查不使用 `skipLibCheck`。
- 浏览器实测 React / Vue 数字输入越界收敛与空值、禁用及错误状态；分页跳转与边界禁用；RadioGroup 方向键选择；Spinner 可见提示。

- 组件实验台可在当前项目主题与默认主题之间切换。实测项目主色 `#526B43` 与默认 `#D43845` 分别生效，深色界面及 390 × 844 移动视口正常，页面无水平溢出。
- Lab 字段间距调整即时更新画布；锁定后对应控件禁用；表格留白同时作用于 React 和 Vue，恢复继承与撤销均生效。验证后已撤销测试主题修改，保留原有项目和品牌锁。
