# 组件参考核对记录

本记录用于持续对照用户提供的 PC 端组件设计稿。范围覆盖其中的基础、反馈、数据展示、输入、导航和通用工具组件；AI Agent 页面不在本轮范围。设计稿的颜色、尺寸与间距不作为目标值，组件仍需遵守 BTDESIGN 的主题与 Lab 规则。

状态必须以代码、组件演示、React/Vue 行为和测试为准；设计图层中出现的名称不等于对应交互已经实现。

## 已开始逐项细化

- 按钮与按钮组：补充尺寸、语义、形状、图标位置，以及按钮组数量和顺序。悬停、焦点、按下由实际交互触发；完整变体矩阵仍需核对。
- 输入框：普通、密码和搜索形式，前后附加项。标签输入、滑动条、时间输入与自动补全分别提供真实控件和预览。滑动条目前仅单值；时间输入使用浏览器原生控件；自动补全仅支持应用传入的本地候选，候选项数字和箭头的业务语义待确认。
- 头像与头像组、折叠面板、标签、描述列表、评论、数值显示、时间轴、步骤条、文字气泡和图片：已有对应双框架实现与演示切换；部分组合和平台输入方式仍需继续核验。数值显示不含倒计时；文字气泡尚不自动避让视口；图片预览不含缩放、旋转和相册切换。
- 日期、表单、选择、树、穿梭、表格与导航已有基础实现；不能由同名推断与参考稿所有变体或业务语义一致。

## 仍须继续逐页核对

数据展示：Badge 的计数/圆点等、Card、Image/Carousel 的全部组合、List 变体、Popover、Timeline、Table 的列类型和筛选浮层、Tree 的层级与样式。

输入：Cascader、Checkbox/Radio 的各类组合、DatePicker、Form、InputNumber、Mention、Select、Switch/Rate、Transfer、TreeSelect、Upload 及设计稿中独立的其他输入类型。组织穿梭中“选择部门”和“选择当前部门成员”具有不同语义，不应以普通静态树多选替代。

导航与工具：Breadcrumb 的分隔形式、Dropdown 的分组及层级、Menu、Tabs 和内页标签、顶部导航、PageHeader、Pagination、Steps，以及 Affix、Anchor、BackTop、ResizeBox 和页面模板。

反馈与其他：Drawer、Message、Modal 各形式、Notification、Popconfirm、各类进度与结果页、Skeleton、Alert；图标、排版、链接、分隔线和实际业务组合也需继续检查。

每完成一项，应检查对应演示切换是否改变真实组件及生成代码，并分别验证 React、Vue、浅色/深色、键盘和当前 Lab 规则。对无法从设计稿确定的业务行为保留问题，不能伪造实现。
